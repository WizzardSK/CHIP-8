# CHIP-8

Thumbnails for CHIP-8 programs, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`, `Named_Titles`), named after the programs' MAME short names, as the MAME `chip8_quik` software list has them.

The frames were made with `tools/c8shot.py`, a small CHIP-8 / SUPER-CHIP interpreter that runs each program without a player, pressing a key now and then, and keeps the first frame with something on it (title) and one about six seconds in (snap). `blackjack`, `dreaminv` and `vddg` are Dream 6800 programs it does not run, so they have none.
